✅ STEP 1: Kill Old Processes

Type:  taskkill /F /IM node.exe

1. Press: Windows Key + R
2. Type:  powershell
3. Press: Enter
4. Paste this:

   cd c:\Users\HP\Documents\quiz-platform\backend && npm start

5. Press: Enter
6. Wait:  15-30 seconds
7. Look for: "✅ Server running on http://localhost:3001"
8. If you see it: ✅ SUCCESS! Go to Step 3


✅ STEP 3: Open Terminal 2 (Frontend)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1. Press: Windows Key + R
2. Type:  powershell
3. Press: Enter

   cd c:\Users\HP\Documents\quiz-platform\frontend && npm run dev

5. Press: Enter
6. Wait:  10 seconds
7. Look for: "➜  Local:   http://localhost:3000/"
8. If you see it: ✅ SUCCESS! Go to Step 4

Problem: "Error: address already in use :::3001"
Solution: Kill processes again with: taskkill /F /IM node.exe

Problem: "Cannot find module"
Solution: Go to backend folder and run: npm install

Problem: Signup says "Signup failed"
Solution:
  1. Look at Backend Terminal for red errors
  2. Check Browser Console (Press F12, go to Console)
  3. Run: node FULL_DIAGNOSTIC.js in a new terminal

Problem: Frontend shows blank page
Solution:
  1. Clear browser cache: Ctrl+Shift+Delete
  2. Reload page: Ctrl+R
  3. Check if port 3000 is showing in terminal
