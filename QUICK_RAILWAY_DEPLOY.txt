🚀 QUICK RAILWAY DEPLOYMENT (Copy-Paste Instructions)

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Run this in terminal:
────────────────────────
railway link

Then select:
- ✅ Create a new Railway project
- Name: quiz-platform-prod
- Select GitHub repo: JohnProgrammin/quiz-platform

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 2: Add environment variables:
──────────────────────────────────
Run this command:

railway up --service backend

This will:
✅ Detect the Dockerfile
✅ Build the image
✅ Deploy to Railway
✅ Give you the URL

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 3: Get your Railway URL:
─────────────────────────────
railway domains

Copy the URL and paste it here in Step 4.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 4: Update Vercel:
──────────────────────
1. Go to https://vercel.com/dashboard
2. Select "quiz-platform" project
3. Settings → Environment Variables
4. Add new variable:
   Name: VITE_API_BASE_URL
   Value: [Railway URL from Step 3]
5. Redeploy from "Deployments" tab

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 5: Test:
─────────────
Visit https://floraquiz.com and sign up/login to test!

If it works → 🎉 You're done!
If it fails → Check Sentry for error details
