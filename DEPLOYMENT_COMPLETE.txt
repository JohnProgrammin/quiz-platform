💡 HOW IT WORKS END-TO-END

   1. User visits floraquiz.com (Vercel frontend)
   2. Frontend sends API request to backend (Render API)
   3. Backend queries PostgreSQL database (Neon)
   4. Redis caches frequently accessed data (Upstash)
   5. Files stored in Cloudflare R2 (S3-compatible)
   6. Groq API generates quiz questions
   7. Paystack processes payments
   8. Resend sends verification emails
   9. Sentry monitors for errors
