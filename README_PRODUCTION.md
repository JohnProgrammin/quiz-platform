## 🆘 Troubleshooting

**Site loads blank?**
→ Check Vercel Deployments tab for errors

**Payment not working?**
→ Verify PAYSTACK_SECRET_KEY in env vars

**Database error?**
→ Check DATABASE_URL and Neon console

**Quiz generation fails?**
→ Verify GROQ_API_KEY is valid

For more, see troubleshooting section in `📖_MASTER_DEPLOYMENT_GUIDE.md`
